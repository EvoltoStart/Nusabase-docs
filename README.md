# Nusabase API Mintlify Documentation Publishing Notes

This repository is the Mintlify documentation publishing repository for Nusabase API, generated by automatic CI sync from the internal GitLab project.

## Publishing pipeline

```text
Internal GitLab project
  -> GitLab CI syncs the documentation allowlist
  -> GitHub repository EvoltoStart/Nusabase-docs
  -> Mintlify automatic deployment
```

## Maintenance rules

- The internal GitLab project is the source of truth for documentation.
- The GitHub repository serves only as the Mintlify publishing repository.
- Manually editing documentation directly in the GitHub repository over the long term is not recommended.
- Adding a new page requires updating both `docs.json` and the sync allowlist in `.gitlab/ci/mintlify-docs.yml` in the internal project.
- The current publication contains English pages only. The synchronization job removes old `zh/` content from the GitHub repository.
- The OpenAPI navigation currently publishes only `docs/en/openapi/relay-api.mintlify.json`.
- `docs/en/openapi/platform-api.json` is kept in the internal project but is not part of the current Mintlify navigation or synchronization allowlist.

## Directory layout

```text
docs/
  en/
    getting-started/    English API getting-started documentation
    guides/             English Agent integration guide
    openapi/            English relay OpenAPI file
  images/                logo and favicon used for Mintlify publishing
```

## Local validation

```bash
node -e "JSON.parse(require('fs').readFileSync('docs.json','utf8')); console.log('docs.json ok')"
node -e "JSON.parse(require('fs').readFileSync('docs/en/openapi/relay-api.mintlify.json','utf8')); console.log('English relay OpenAPI ok')"
npx -y @redocly/cli lint docs/en/openapi/relay-api.mintlify.json --max-problems 30
```
